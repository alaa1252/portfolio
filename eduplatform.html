EduPlatform

A dynamic EdTech application featuring course catalogs, advanced client-side filters, a fully functional CRUD dashboard, local state management, and seamless Dark Mode support.

Live Demo GitHub

Overview

EduPlatform is a rich, single-page educational application built with React and TailwindCSS. It replicates the complete client experience of modern e-learning tools, offering robust catalog browsing, mock multi-role dynamic flows, blog aggregation via third-party APIs, and a dashboard supporting full CRUD operations powered by persistent local storage.

Problem

The goal was to build a comprehensive, multi-view React application that showcases scalable UI architectures. Key challenges addressed include global state synchronization across separated pages, advanced front-end sorting and filtering algorithms, localized state persistence, dynamic client-side routing, and explicit structural form validation.

Key Features

  • Comprehensive Dashboard containing complete client-side CRUD capabilities for resource management
  • Advanced Course Catalog featuring real-time Search, multi-tier Dropdown Filters, Sorting, and client-side Pagination
  • Unified Global State management handling dynamic user updates, UI modes, and data modifications cleanly via action dispatchers
  • Asynchronous external integration using a robust custom hook to populate a live public blog system
  • Highly accessible interface featuring complete Dark Mode support, fluid RTL spacing, and clean custom form validations
  • Strict client-side routing control including protective error handle fallbacks (404 views) and clean query-based parsing

Challenges

Complex State Management Without Redux

Managing extensive dashboard interactions, dark mode toggles, and multi-field catalogs across isolated components could easily cause prop-drilling or un-syncable UI updates. This was cleanly solved by implementing a unified React Context framework backed by a structured useReducer architecture, simulating structured, scalable data streaming.

Reliable Client-Side CRUD & Persistence

Providing interactive addition, editing, and deletion of content across pages without a specialized cloud database requires stable caching boundaries. Utilizing a localized serialization layer via browser localStorage allowed safe data mutations to persist seamlessly between full tab reloads.
